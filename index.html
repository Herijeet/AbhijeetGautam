02 / Featured project

Custom Report Platform

Problem
Every asset-management client gets its own Excel workbook. Each one was hand-coded in a legacy VB.NET desktop application, so a new format meant a developer and a release.
What I built
A platform where an author uploads the client's own workbook. The engine detects its tables and headers, binds each column to a data point, and saves the result as a versioned JSON package. Reports then run on demand or on a schedule and are mailed to the client.
How it works

Angular 22 front end → YARP API gateway → .NET 10 orchestration service (Quartz scheduling, mail outbox, permissions) → gRPC → Python 3.12 calculation engine (FastAPI, Polars and DuckDB over Parquet).

A query builder parses SQL into an intermediate representation, validates it and runs it on DuckDB, with caching that collapses identical concurrent requests.

Result
32 client reports migrated. Each generates in under 5 minutes from the UI. Output matches the legacy system cell by cell at 98% or better, with every remaining difference traced to a data cause. New formats are configuration, not code.
